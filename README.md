# موقع جريد

موقع تعريفي عربي لعلامة جريد، المتخصصة في تصميم وتصنيع قوالب السيليكون المخصصة للشوكولاتة والتيراميسو.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## التحقق والبناء

```bash
npm run build
npm run build:vercel
```

## النشر على Vercel

اربط هذا المستودع بمشروع جديد في Vercel. يحدد ملف `vercel.json` أمر البناء المناسب تلقائياً، ولا يحتاج الموقع إلى متغيرات بيئة.

جميع أزرار الطلب والتواصل الرئيسية تفتح واتساب على الرقم المعتمد في ملفات جريد.
